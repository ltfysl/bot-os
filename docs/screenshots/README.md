# BotOS Desktop UI Screenshots

This directory contains screenshots of the BotOS desktop application showing the current state of the UI.

## Screenshots

### botos-shell.png
Full shell view showing the main UI with agent rail (sidebar) and chat interface. Shows the overall application layout with agents list on the left and active chat on the right.

### botos-chat.png
Detailed chat view showing the dense chat interface with message history and the message composer. Demonstrates the conversational interface with AI agents.

### botos-rooms.png
Rooms view showing the multi-agent Team Chat interface. Displays how multiple agents can collaborate in shared rooms.

## Details

- **Resolution:** 1399x874 pixels
- **Format:** PNG with 8-bit RGBA
- **Captured from:** main branch
- **Date:** September 7, 2026

These screenshots represent the current UI state of BotOS, a desktop multi-agent application with third-party AI providers built on Electron, React, and TypeScript.
